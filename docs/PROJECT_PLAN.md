# 项目规划 v0.2

更新：2026-11-01，已按用户补充收敛为询盘站。

## 已确认范围

- 仅做商品展示与询盘，不做在线购买、购物车、结算、支付、会员和管理后台。
- 品牌名参考 Ellis Brooklyn，布局、图片、商品资料最大程度沿用原站；原始文件保留，独立实现 Astro 组件。
- 面向欧美，全站 English，支持 USD / EUR 展示及询盘时选择币种。
- 最新稳定 Astro，后续同步已有 GitHub 仓库 highertq/xiangshui，部署 Cloudflare。
- 询盘不自动等同于批发/OEM；不擅自添加 MOQ、定制能力或厂家声明。

## 页面范围

| 页面 | 路由 | 内容 |
| --- | --- | --- |
| 首页 | `/` | 尽量沿用参考站首屏、畅销、专题拼图、品牌区与页脚结构 |
| 系列列表 | `/collections/[slug]` | 分类、香调/容量筛选、排序、无结果状态 |
| 商品详情 | `/products/[slug]` | 图集、香调、规格、参考信息、Inquire Now |
| 搜索 | `/search` | 本地商品搜索及空状态 |
| 询盘 | `/inquiry` | 自动带入商品/规格，填写数量、目的国、姓名、邮箱、需求与 USD/EUR 偏好 |
| 品牌/联系 | `/about`、`/contact` | 品牌展示、真实经营联系方式与询盘入口 |
| 服务/政策 | `/faq`、`/privacy`、`/terms` | 根据实际业务编写；配送/退换独立页待资料齐备再决定 |
| 404 | `/404` | 正确状态码与返回入口 |

原站 Add to cart 改为 Inquire Now，Cart/Login 入口调整为联系或询盘入口；保留视觉语言但购买功能适配询盘目标。订阅、赠品、视频购物和评价不作为首期必备功能。

## 数据与币种

商品资料从本地参考文件整理到结构化数据，通过源码更新，无可视化后台。美元与欧元分别配置金额，未经确认不将原站价格当作本项目报价，不直接把美元数字换上欧元符号。价格尚未确定时显示 Request a quote，仍允许选择询盘币种。正式报价由经营者线下回复。

## 验收标准

- check/build 通过，页面无明显溢出、缺图、死链接；菜单与表单可键盘操作。
- 商品/规格自动带入询盘，币种跨页保持；无价格时不出现 NaN 或伪造报价。
- 输入校验，提交过程中防重复；失败保留填写内容；仅服务确认接受后显示成功，投递上线验收需在收件端核实。
- 未接投递服务时明确演示状态，不显示虚假发送成功。
- title、description、canonical、站点地图和真实内容匹配；不伪造评价、库存和 Offer 数据。
- 首屏图片优化，非首屏延迟加载，目标 LCP ≤ 2.5s、CLS ≤ 0.1、INP ≤ 200ms，实际结果在上线后测量。
- 预览禁止索引，生产检查 HTTPS、商品直达、404、表单和部署回滚版本。
