## 首页模块建议

公告 → 主导航 → 品牌主视觉 → 畅销商品 → 系列专题 → 品牌故事 → 精选系列 → 社交内容 → 服务页脚。

首期将视频、媒体背书和社交模块设计为可选；无真实内容则隐藏。促销内容由配置驱动，不能继承原站优惠条件。

## 视觉基线

- 白色主背景、黑色文字和深色页脚，商品摄影提供丰富颜色。
- 无衬线字体，大写粗标题，按钮适度字距；具体字体需核对授权后选择。
- 商品卡片避免厚阴影与过度容器化；图片、名称、价格和按钮形成稳定节奏。
- 专题采用错位构图，移动端重新排列为清晰阅读顺序，不能缩小整张桌面布局。
- 只对照网页内容区，不复制浏览器地址栏、SEOquake 侧栏、扩展工具和系统边框。
- 移动端导航使用抽屉，商品至少可在小屏清晰阅读；横向列表提供滑动及键盘可用入口。
- 首屏第一张主图优先；若启用自动轮播必须能暂停，并尊重减少动态效果设置。

## 素材处理策略

保留原目录，只将获得确认的新站素材复制到 `src/assets/`，记录来源与用途；大视频另评估托管。截图和 HTML 中的图片不是新站商用素材库，原站字体、品牌标识和人物素材也不自动视为可用。

建议建立素材清单：文件名、用途、桌面/手机尺寸、alt、来源、是否允许发布。重复尺寸先去重，再由 Astro 图片管线输出响应式图片。
